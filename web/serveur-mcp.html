Serveur MCP · gratuit · sans compte

Votre IA, connectée à la jurisprudence française.

JusticeLibre permet à Claude, ChatGPT, Mistral, Cursor ou à tout client MCP de rechercher, lire et citer les décisions françaises et européennes, et les articles de loi dans leur version à une date donnée. Il n'y a ni compte, ni clé, ni connexion : collez cette adresse dans votre assistant.

https://justicelibre.org/mcp

Installer, en deux minutes

Le serveur utilise le transport « Streamable HTTP ». Aucune authentification n'est demandée : si votre client propose un choix, sélectionnez « Aucune ».

  1. Sur claude.ai ou dans Claude Desktop : Paramètres › Connecteurs › Ajouter un connecteur personnalisé.
  2. Nom : JusticeLibre. URL : https://justicelibre.org/mcp. Laissez les paramètres OAuth vides.

Dans une conversation, activez JusticeLibre dans le menu des outils, puis posez votre question.

  1. Activez le mode développeur dans les paramètres de ChatGPT (rubrique sécurité et connexion, selon les versions).
  2. Ajoutez une application MCP personnalisée (menu des plugins ou des applications : Ajouter › Créer). Nom : JusticeLibre, URL : https://justicelibre.org/mcp, authentification : aucune.

Réservé aux offres payantes qui proposent le mode développeur (Plus, Pro…). L'emplacement des menus change souvent chez ChatGPT.

  1. Sur chat.mistral.ai : Contexte › Connecteurs › Ajouter un connecteur › Connecteur MCP personnalisé.
  2. Nom : JusticeLibre, URL : https://justicelibre.org/mcp, authentification : aucune.

Dans un terminal :

claude mcp add --transport http justicelibre https://justicelibre.org/mcp

Cursor : fichier mcp.json

{"mcpServers": {"justicelibre": {"url": "https://justicelibre.org/mcp"}}}

VS Code : fichier .vscode/mcp.json

{"servers": {"justicelibre": {"type": "http", "url": "https://justicelibre.org/mcp"}}}

Zed : réglages, clé context_servers

{"context_servers": {"justicelibre": {"url": "https://justicelibre.org/mcp"}}}

Autre client : ajoutez un serveur MCP distant (Streamable HTTP, sans authentification) à l'adresse https://justicelibre.org/mcp, selon sa documentation.

Ce qui est garanti

Aucun compteNi inscription, ni clé, ni OAuth. L'adresse suffit.
Sources officiellesChaque résultat porte son identifiant officiel et, quand la source en publie une, le lien vers sa page (Légifrance, Cour de cassation, Conseil d'État, HUDOC, EUR-Lex).
Pas de référence approchanteUn numéro introuvable renvoie une erreur, jamais une décision voisine.
Lecture seuleLe serveur ne fait que lire : il ne modifie rien et ne demande aucune donnée personnelle.
Une IA peut se tromper en résumant une décision. Avant de citer, ouvrez la décision ou l'article : chaque résultat donne son identifiant et le lien vers sa page.
